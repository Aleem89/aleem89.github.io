# aleem89.github.io

Personal site for Aleem Sattar — software engineer, data platform. Plain HTML, CSS, and JavaScript; no build step.
Served by GitHub Pages from the `main` branch root.

- `index.html` — the page
- `css/styles.css` — dark theme, responsive layout
- `js/main.js` — live Dallas date/time chip, scroll-spy, reveal animations, copy-email button
- `assets/Aleem_Sattar_Resume.pdf` — downloadable resume (regenerate from `~/Documents/resume/source`)

Preview locally: `python3 -m http.server 8080` and open http://localhost:8080.
